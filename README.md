# TRCE releases

Android APK downloads for TRCE, the offline-first run and walk tracker.

**Latest:** [trce.apk](https://github.com/jlstrr/trce-releases/releases/latest/download/trce.apk)

Install it on an Android phone, allowing installs from your browser when asked. GPS tracking, offline maps and route planning work with no signal, and every activity stays on the phone.
